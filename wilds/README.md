# Wilds

2D-игра для телефона с видом как в Don't Starve: плоские спрайты, камера 3/4 сверху, сортировка по Y.
Godot 4.3, GL Compatibility, ландшафт. Главная героиня: Мита (аниме-стиль, чёрная куртка, длинные чёрные волосы, светящиеся синие глаза, катана с фиолетовой рукоятью). Палитра ночных руин: индиго и фиолет.

## Вид
- `Node2D` с `y_sort_enabled`: кто ниже на экране, тот поверх. Начало координат объекта у его основания.
- Тени и пятна земли сплющены по Y, вертикальная скорость игрока 0.75 от горизонтальной.
- Плиты площадки нарисованы в изометрии 2:1.

## Файлы
- `main.gd` мир, камера, виньетка, интерфейс, кадры предпросмотра для CI
- `player.gd` Мита: три ракурса (спереди, сзади, сбоку), шаг, волосы, светящиеся глаза и клинок
- `prop.gd` мёртвое дерево, камень, колючий куст, колонна
- `ground.gd` земля, плиты, лужи, трава
- `joystick.gd` плавающий джойстик (левая половина экрана)

Спрайты пока рисуются кодом. Заменяются на нарисованные PNG без смены логики.

## Сборка
GitHub Actions: `.github/workflows/wilds.yml`. Пуш в ветку `wilds` запускает проверку скриптов, дымовой тест, экспорт APK и публикует его в релиз `wilds-latest`. Кадры предпросмотра лежат в ветке `wilds-preview`.
На компьютере: `godot --path wilds` (WASD).
