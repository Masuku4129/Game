# Тайга — рабочая очередь и контроль APK

Этот документ — единая контрольная точка проекта. Порядок работ не меняется без причины; выполненная задача отмечается только после фактического изменения файлов и проверки.

## Цель текущего этапа
Получить устанавливаемый Android APK и улучшить видимый игровой мир, а не только документацию.

## Очередь (порядок)

1. **Стабильная сборка APK (блокирующая цель).**
   - Проверить Android workflow, импорты Godot, экспорт моделей, smoke test и фактический APK artifact.
   - Если сборка падает — исправить первопричину и повторить запуск.
2. **Импортируемые модели / читаемый визуальный стиль.**
   - Проверить модели GLB, материалы, масштаб, pivot, LOD, коллизии и галерею.
   - Расширять природные виды и формы/варианты; не считать процедурные шары/конусы окончательными моделями.
3. **Персонаж.**
   - Проверить импортируемый skinned mesh, одежду/снаряжение, скелет, крепления в руках, переходы Idle/Walk/Run/сбор/рубка.
4. **Живой лес и плотность.**
   - Смешанный лес: хвойные и лиственные виды, кусты, папоротники, мхи, травы, пни, валежник.
   - Разнообразие форм и возрастов, плотность и производительность Android.
5. **Взаимодействие с окружением.**
   - Следы в снегу и грязи, проминание травы, снег на ветвях, ветер/дождь, сезонные состояния; влияние на скорость и состояние игрока.
6. **Выживание.**
   - Исследование, сбор, охота, рыбалка, инструменты, строительство, укрытие, костёр, голод/жажда/усталость/температура.
7. **Приёмка на устройстве.**
   - Проверка APK на Android; визуальные дефекты, управление, производительность, коллизии и UI.

## Проверяемые файлы/системы уже в репозитории

- Модели природы: `game/models/environment/`
- Галерея моделей: `game/scenes/asset_gallery.tscn`, `game/scripts/asset_gallery.gd`
- Генератор/экспорт: `game/scripts/veg.gd`, `game/scripts/export_game_style_models.gd`
- Персонаж: `game/scripts/hero_skin.gd`, `game/scripts/hero.gd`
- Погода и следы: `game/scripts/weather.gd`, `game/scripts/footprints.gd`
- Животные: `game/scripts/animal.gd`, `game/scripts/animal_model.gd`
- Android workflow: `.github/workflows/android.yml`

## Правила статуса

- **Не готово** — есть только идея/описание или непроверенный код.
- **В работе** — есть конкретные изменения, но не завершена проверка.
- **Проверено** — есть свежие результаты запуска/тестов, соответствующие задаче.
- APK считается готовым только при успешном workflow и наличии файла APK в artifact/release. Успешная сборка не заменяет визуальную проверку на телефоне.

## Текущая проверка

- [x] Репозиторий и рабочая ветка доступны через GitHub.
- [x] Android workflow существует и запускается push в `main` и `parallel/**`.
- [x] Проект содержит импортируемые GLB-модели природы и системы погоды/следов.
- [ ] Свежий успешный APK workflow и скачиваемый APK artifact — **не подтверждены на этом шаге**.
- [ ] Проверка внешнего вида/управления на реальном Android — **не выполнена**.

## Сборка APK

Push в рабочую ветку запускает `.github/workflows/android.yml`. APK доступен в GitHub Actions → workflow run → Artifacts (artifact `taiga-apk`) после успешного job `export`. Публикация prerelease `latest` также настроена workflow, но наличие актуального APK нужно проверять по свежему run.
