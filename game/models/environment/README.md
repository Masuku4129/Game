# Taiga environment model pack (живописный стиль)

Оригинальные низкополигональные GLB (glTF Binary, Y-up, Godot 4). Генерация: `python tools/generate_taiga_models.py`, CI: `generate-taiga-models.yml`.

Стиль игры: кроны — мягкие округлые «облака» или рваные ярусы-юбки с радиальными нормалями, стволы — конусные трубки с честными UV.
Фототекстур нет: цвет, мазки, тёплый свет и холодные тени, снег, осень, влага и растворение дают штатные шейдеры игры (`shaders/paint/*`).
Материалы назначает `pveg.model_variants()` по имени меша: `bark` (кора породы), `foliage` (крона породы), `cut` (спил), `rock`.

Дальние деревья и папоротник, трава, мох, камни, валежник остаются штатными процедурными (`pveg.gd`).
