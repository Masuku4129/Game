# Taiga environment model pack (живописный стиль)

24 оригинальные низкополигональные GLB (glTF Binary, Y-up, Godot 4). Генерация: `python tools/generate_taiga_models.py`, CI: `generate-taiga-models.yml`.

Стиль игры: кроны — мягкие округлые «облака» или рваные ярусы-юбки с радиальными нормалями, стволы — конусные трубки с честными UV.
Фототекстур нет: цвет, мазки, тёплый свет и холодные тени, снег, осень, влага и растворение дают штатные шейдеры игры (`shaders/paint/*`).
Материалы назначает `pveg.model_variants()` по имени меша: `bark` (кора породы), `foliage` (крона породы), `cut` (спил), `rock`.

В набор входят отдельные модели: ель, сосна, лиственница, кедр, берёза, осина, ольха, пихта, ива, рябина, можжевельник, лещина, шиповник, сухая берёза, куст, папоротник, камыш, осока, мох, гриб, цветы, пень, валун и валежник.

Реестр моделей и происхождение: `ASSET_REGISTER.md`. Изолированная галерея `res://scenes/asset_gallery.tscn` показывает все 24 категории, зарегистрированные в `pveg.gd`. Наличие GLB не означает, что каждая категория уже полностью заменяет все процедурные подварианты в игровом мире.
