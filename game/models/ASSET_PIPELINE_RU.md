# Библиотека 3D-ассетов «Тайга»

## Назначение
Единый реестр моделей, которые можно импортировать в Godot 4.x. Основной переносимый формат — glTF 2.0 / GLB. Все модели должны иметь реальную геометрию, корректные нормали и материалы.

## Правила ассетов
- Масштаб: метры, вертикальная ось Y, основание модели на Y=0.
- Цвета: правдоподобные природные оттенки; не использовать фэнтезийные свечения.
- Имена: `category_species_variant`, например `tree_birch_a`.
- Варианты одного вида должны различаться силуэтом, ветвлением и пропорциями, а не только масштабом.
- Мобильная оптимизация: один-два материала на объект, умеренное число полигонов, простые коллизии отдельно от визуального меша.
- Сезонные версии обозначать суффиксами `_spring`, `_summer`, `_autumn`, `_winter`.

## Очерёдность библиотеки
| Группа | Необходимые модели |
|---|---|
| Деревья | ель, сосна, лиственница, берёза, осина, ольха, сухостой |
| Подлесок | кусты, ягодники, папоротник, трава, камыш, мох |
| Лесной мусор | пни, корни, валежник, ветви, шишки, кора |
| Геология | валуны, осыпи, скальные выступы, галька |
| Вода и грунт | береговые кромки, грязевые участки, лужи, снеговые наносы |
| Постройки | шалаш, навес, землянка, изба, костровище, сушилка |
| Снаряжение | топор, нож, копьё, лук, котелок, рюкзак |
| Животные | медведь, волк, лось, кабан, лиса, заяц, бобр, птицы |
| Персонаж | тело, одежда по слоям, обувь, головной убор, снаряжение |

## Первичная партия
Начальный набор, подготовленный в этой ветке:
- берёза — `tree_birch_a`
- ель — `tree_spruce_a`
- ель (вариант) — `tree_spruce_b`
- папоротник — `fern_cluster_a`
- мшистый камень — `rock_moss_a`
- старый пень — `stump_old_a`
- куст с ягодами — `bush_berry_a`
- кочка травы — `grass_tussock_a`
- корни — `root_cluster_a`
- упавшее бревно — `fallen_log_a`

## Проверки перед подключением
1. Проверить структуру glTF и наличие вершин, индексов, нормалей и материалов.
2. Импортировать модель в Godot без ошибок.
3. Проверить масштаб, pivot, ориентацию и тени.
4. Проверить читаемость с игровой камеры и на мобильном разрешении.
5. Не считать ассет интегрированным в игру до появления в сцене и проверки Android-сборки.
