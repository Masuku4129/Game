# Природные модели «Тайги»

Первые шесть self-contained glTF 2.0-ассетов:
- `tree_spruce_a.gltf` — ель с ярусами хвои и ветвями.
- `tree_birch_a.gltf` — берёза с ветвлением и многослойной кроной.
- `fern_cluster_a.gltf` — группа папоротников.
- `rock_moss_a.gltf` — неровный камень с мхом.
- `stump_old_a.gltf` — пень.
- `fallen_log_a.gltf` — упавшее бревно.

Каждая модель содержит встроенный бинарный буфер, позиции, нормали и vertex colors. Внешние текстуры не требуются. Модели подготовлены как первая геометрическая партия; финальная художественная проверка и подключение к генератору мира ещё впереди.

Проверка из корня репозитория:
```bash
python3 tools/validate_taiga_gltf.py
```
