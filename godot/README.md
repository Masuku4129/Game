# Wildlands — Godot mobile prototype

This is an isolated Godot project inside the existing Android repository. Existing Android source files are preserved.

## Current implementation
- Landscape project settings and a fixed, follow camera
- Procedurally created forest (trees, shrubs, ground color variation)
- Basic player movement and simple touch movement input
- Weather cycling: clear, cloudy, rain, fog
- Mobile-compatible GL Compatibility renderer

## Planned next work
- Replace placeholder player geometry with a coherent low-poly character model and rig
- Better foliage meshes and ground materials; terrain variation
- Reliable thumbstick UI and movement tests
- Weather effects with ground wetness/footprint state
