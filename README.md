# Тайга

Мобильная 3D survival-игра о землепроходце в дикой природе Сибири и Дальнего Востока. Godot 4.3, Android, горизонтальный экран, фиксированная изометрическая камера.

## Точка входа проекта

- **Визуальные требования и критерии приёмки:** [ART_DIRECTION.md](ART_DIRECTION.md)

- **GitHub Actions / APK:** [последние сборки](https://github.com/Masuku4129/Game/actions)

## Текущий этап: перевод окружения на GLB

В репозитории есть 11 импортируемых GLB-моделей: ель, сосна, лиственница, кедр, берёза, осина, ольха, куст, пень, валун и валежник. Они назначаются материалами штатной toon/painterly-системы игры.

В основную генерацию мира уже переведены поддержанные GLB-категории: деревья, куст, пень, камни и валежник. Эти модели используются как в ближнем, так и в дальнем MultiMesh; для них больше не выбирается процедурная геометрия на дальней дистанции.

**Миграция ещё не завершена:** трава, папоротники, камыш, мхи, ягоды, грибы, цветы, мелкий лесной мусор и часть специальных вариантов растительности пока используют процедурные меши. Следующий этап — создать для них отдельные GLB-ассеты, подключить сезонные материалы и коллизии, затем убрать оставшиеся процедурные генераторы из игрового окружения. Галерея CI проверяет 11 GLB-моделей.

## Сборка

APK собирается автоматически через GitHub Actions при push в `main` и публикуется в prerelease `latest`. Успешная APK-сборка не означает, что отдельная визуальная проверка моделей прошла: смотрите статус обоих заданий в Actions.
