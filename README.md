# Game

Мобильная 3D-игра о выживании в природной среде Дальнего Востока.

## Проект

- Главный документ требований: [PROJECT_MASTER.md](PROJECT_MASTER.md)
- Структура и ответственность модулей: [docs/PROJECT_STRUCTURE.md](docs/PROJECT_STRUCTURE.md)
- Движок: Godot 4.7.2 (первоначальная техническая база)
- Целевая платформа: Android / APK
- Автоматическая сборка: GitHub Actions

## Получение APK

Каждое изменение исходников в основной ветке запускает workflow **Android APK**. После успешной сборки APK находится в Artifacts соответствующего запуска GitHub Actions.

## Статус

Проект находится на ранней стадии разработки. Наличие сборочного конвейера и стартовой сцены не означает, что все игровые системы из PROJECT_MASTER.md уже реализованы.
