# Тайга

Мобильная 3D survival-игра о землепроходце в дикой природе Сибири и Дальнего Востока. Godot 4.3, Android, горизонтальный экран, фиксированная изометрическая камера.

## Точка входа проекта

- **Проект Godot:** `game/`
- **Визуальные требования и критерии приёмки:** [ART_DIRECTION.md](ART_DIRECTION.md)
- **Игровые системы и план выживания:** [GAMEPLAY_SYSTEMS.md](GAMEPLAY_SYSTEMS.md)
- **Импортируемые модели окружения:** [game/models/environment](game/models/environment/)
- **Генератор игровых GLB-моделей:** [game/scripts/export_game_style_models.gd](game/scripts/export_game_style_models.gd) — использует штатные меши и текстуры `veg.gd`.
- **Изолированная галерея GLB:** [game/scenes/asset_gallery.tscn](game/scenes/asset_gallery.tscn)
- **GitHub Actions / APK:** [последние сборки](https://github.com/Masuku4129/Game/actions)

## Формат игры

Одиночная игра: один управляемый первопроходец. Режим отряда/острога не является частью релизного игрового процесса.

## Текущий этап: расширение живого мира и игровых систем

Сборка создаёт пять основных импортируемых GLB-моделей непосредственно из штатного генератора `veg.gd` и его игровых текстур: ель, сосну, берёзу, куст и камень. Они подключаются как ближняя геометрия; дальний LOD остаётся на общей системе генерации. Галерея сравнивает старый пакет и модели в графике игры. Модель первопроходца и его экипировка остаются отдельным направлением работ; релизный режим рассчитан на одного управляемого персонажа.

Текущий план и критерии приёмки ведутся в `ART_DIRECTION.md` и `GAMEPLAY_SYSTEMS.md`. Наличие модели или скрипта само по себе не считается подтверждением готовности — требуется запуск и игровой тест.

## Сборка

APK собирается автоматически через GitHub Actions при push в `main` и публикуется в prerelease `latest`. Успешная APK-сборка не означает, что отдельная визуальная проверка моделей прошла: смотрите статус обоих заданий в Actions.


## Единый стиль моделей и бюджет мобильной графики

Целевой стиль — стилизованный природный реализм: читаемые силуэты, слегка упрощённые формы, асимметричные кроны, естественная вариативность, приглушённая палитра и матовые материалы. Не смешивать скан-фотореализм, игрушечный low-poly и примитивные placeholder-сборки.


**Общая палитра:** хвоя `#31563B`/`#243E2D`; освещённая хвоя `#57784A`; моховые листья `#647C45`; осенние `#A17B45`; древесина `#65513C`; берёза `#C9C6B4`; камень `#555B57`; лишайник `#89966B`; лесная подстилка `#514438`; мох `#536B43`; грязь `#3E3A31`; вода `#536C68`; снег `#D6D9D4`.

**Стандарты ассетов:** GLB Y-up, основание модели в origin, метры, применённые трансформации, малое число материалов, объединённая геометрия и vertex colors. Детализация только на расстоянии, где она читается. Коллизии отдельные и простые, не использовать render mesh для физики. Листва должна поддерживать общие сезонные эффекты ветра, снега, влажности и осеннего изменения цвета.

**LOD:** Near — детали и взаимодействие, простые физические proxy; Mid — сокращённые ветви/листва, без теней мелких объектов; Far — силуэтные меши, сгруппированные по виду и пространственной клетке, без физики. При приёмке проверять палитру, масштаб, силуэт, число треугольников, поверхностей/материалов, коллизии и CPU/GPU стоимость.
