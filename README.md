# Тайга

Мобильная 3D survival-игра о землепроходце в дикой природе Сибири и Дальнего Востока. Godot 4.3, Android, горизонтальный экран, фиксированная изометрическая камера.

## Точка входа проекта

- **Проект Godot:** `game/`
- **Визуальные требования и критерии приёмки:** [ART_DIRECTION.md](ART_DIRECTION.md)
- **Импортируемые модели окружения:** [game/models/environment](game/models/environment/)
- **Генератор моделей:** [tools/generate_taiga_models.py](tools/generate_taiga_models.py)
- **Изолированная галерея GLB:** [game/scenes/asset_gallery.tscn](game/scenes/asset_gallery.tscn)
- **GitHub Actions / APK:** [последние сборки](https://github.com/Masuku4129/Game/actions)

## Текущий этап: импорт и визуальная проверка моделей

Пять отдельных GLB-моделей окружения уже созданы: ель, берёза, куст, камень и валежник. Галерея загружает их через штатный импортёр Godot. Она изолирована от основной сцены и пока не заменяет штатную процедурную систему леса.

Критерий следующего шага: успешный импорт GLB в Godot, рендер галереи без ошибок, визуальная оценка силуэтов/материалов и только после этого — выбор моделей для интеграции в мир.

## Сборка

APK собирается автоматически через GitHub Actions при push в `main` и публикуется в prerelease `latest`. Успешная APK-сборка не означает, что отдельная визуальная проверка моделей прошла: смотрите статус обоих заданий в Actions.
