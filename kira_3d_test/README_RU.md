# Тест управления Kira (ходьба, бег, удар)

Содержимое: папка `kira_3d_test/` (проект Godot 4.3) и `.github/workflows/kira-3d-test-apk.yml`.
Существующие папки репозитория не затрагиваются.

1. Скопируй обе части в корень репозитория Masuku4129/Game, закоммить.
2. GitHub → Actions → "Kira 3D test APK" → Run workflow (или сработает на push).
3. После сборки скачай артефакт `kira-test-apk` (внутри kira_test.apk и selftest.log) и установи на телефон.

Управление: левый джойстик (слабый наклон = ходьба, сильный = бег), справа кнопка УДАР.
На ПК: WASD, Shift = бег, Space/J = удар.
