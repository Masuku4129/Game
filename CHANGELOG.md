# Тайга — изменения

## Изменено
- Увеличено в 2.5 раза количество попыток размещения объектов растительного лесного набора при генерации: деревья, кустарники, папоротники, болотные растения, ягодники, мелкая растительность и лесной мусор. Это применяется к прежнему набору процедурных моделей, правилам биомов, занятости, MultiMesh и LOD, без удаления прежних видов.
- CI теперь строго завершает проверку при ошибке Godot script check, вместо прежнего конвейера grep, который мог скрывать ошибку.
- CI упаковывает полный исходный проект игры вместе с документацией в taiga-project.zip, публикует ZIP и APK как артефакты и прикладывает оба к Release latest.

## Сохранено
- Все существующие сцены, скрипты, модели, текстуры, погодные эффекты, следы, инструменты, животные, охота, рыбалка, строительство, инвентарь, ремесло, колония и интерфейс остаются в репозитории без удаления.

## Допущения
- Под «2.5× плотнее» принято увеличение числа попыток размещения лесной растительности в 2.5 раза. Существующие проверки биомов, коллизий/занятости, высоты, уклона, LOD и дальности видимости продолжают ограничивать фактическое количество экземпляров.
- Из-за отсутствия локального Godot 4.3 и Android export SDK в этой среде, реальный запуск/экспорт APK не подтверждён локально. Проверку и экспорт выполняет GitHub Actions при коммите.

## Проверка на телефоне
1. Установить APK из Release latest или артефакта Actions.
2. Начать новую игру и исследовать густой лес, редколесье, болотистые участки, берега, склоны и поляны.
3. Проверить столкновения со стволами/камнями, сбор и рубку, анимацию падения деревьев, следы, траву, сезон и погоду.
4. Открыть короб и ремесло, прокрутить список рецептов до конца, проверить выбор и изготовление, а также размещение предметов в руке/на поясе/за спиной.
5. В GitHub Actions открыть taiga-apk-and-project и скачать taiga-project.zip вместе с APK.
