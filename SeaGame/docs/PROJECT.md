# Sea Game — Project Brief

## Core theme
A new standalone game project about the sea. The sea is the central environment and gameplay subject—not just a background.

## Design principles
- Make the ocean and coastal world feel alive and visually distinctive.
- Build systems that interact: water, weather, wind, waves, environment, objects, and player actions.
- Prioritize a playable, cohesive experience over disconnected features.
- Keep this project independent from other game projects in the repository.

## Decisions not yet locked
- Genre and core gameplay loop
- Setting and world scale
- Art style
- Camera and controls
- Platform and engine
- Player role and progression

## Initial production sequence
1. Define the game identity and core loop.
2. Lock visual direction and camera.
3. Create representative sea, shoreline, boat, and character assets.
4. Implement a small playable environment.
5. Expand water/weather interactions and content.
