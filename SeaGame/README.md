# Sea Game

A separate new game project centered on the sea and maritime environments.

This directory is intentionally isolated from the existing wilderness-survival game. The concept, art direction, gameplay, technology, and production plan will be developed here.

## Project status
- **Stage:** project foundation
- **Focus:** sea, ocean, coastal environments, water systems, and maritime gameplay
- **Next:** establish the core game concept and visual direction, then build the first playable prototype

## Project structure
- `docs/` — project decisions and design notes
- `art/` — visual direction, models, textures, animation, and asset notes
- `gameplay/` — gameplay systems and mechanics
- `technical/` — engine, architecture, and implementation notes

See [Project Brief](docs/PROJECT.md) for the starting brief.
